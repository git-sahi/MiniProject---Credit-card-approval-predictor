Credit Card Approval Prediction System

A machine learning project designed to streamline the credit approval process by making it faster, more scalable, and more accurate.

Features:

Users enter their details, including:
Age
Gender
Annual Income
Housing Type
Assets Owned
Existing Loan Obligations
A trained machine learning model predicts the applicant's likelihood of repaying the loan, assisting in the credit approval decision.

Tech Stack:

Python
NumPy
Pandas
Scikit-learn
Flask
Seaborn

Machine Learning Algorithms Used:

Logistic Regression
Decision Tree Classifier
Random Forest Classifier

Data Preprocessing Techniques:

Z-score Normalization
Feature Engineering
Data Cleaning and Encoding

Results:

Achieved 97% prediction accuracy.
Obtained high precision and recall scores, demonstrating reliable classification performance.
